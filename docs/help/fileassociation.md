# File associations

XML Notepad can appear in File Explorer’s **Open with** list for `.xml`, `.xsd`, `.xsl`, and `.xslt`. To open one file, right-click it and choose **Open with > XML Notepad**.

To use XML Notepad by default, open **Help > File Associations**. If you are running a portable copy, choose **Register and open Settings** first. In Windows **Default apps**, look up each extension you want to change and choose XML Notepad.

If you move a portable copy, open **Help > File Associations** from its new folder to refresh its registration.
