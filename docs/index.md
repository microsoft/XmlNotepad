# XML Notepad

XML Notepad lets you browse and edit an XML document as a tree. Open a file, expand an element, and edit its value beside its name. You can move a branch, check a document against a schema, or compare two versions of the same file.

- [Install XML Notepad](install.md)
- [Open a document and make your first edit](help/overview.md)
- [Find and replace text or use XPath](help/find.md)
- [Add a schema and validate a document](help/schemas.md)
- [Build from source](dev/index.md)

## About the project

Murray Low wrote the original XML Notepad in C++, and Microsoft released it in 1998. Chris Lovett later rewrote the editor in C# using `System.Xml`. Michael Corning and Dan Doris helped develop and test that version. The 3.0 source tree uses WinUI 3 and .NET 11.

The [source code and release downloads](https://github.com/microsoft/XmlNotepad) are on GitHub. Questions, bug reports, and feature requests are welcome in [GitHub Issues](https://github.com/microsoft/XmlNotepad/issues).
